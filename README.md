# AutoRespawn

The AutoRespawn Mod displays the death screen for a short delay before respawning automatically. 
It removes the need to manually click the respawn button, ensuring a seamless gameplay experience. 
The mod is client-side and works even on vanilla servers without requiring server-side installation.
